World Wide Web

Projeto de hipertexto em rede, CERN, Genebra, 1991.

O que é a Web?

A WWW é uma iniciativa para buscar informação por hipermídia em redes de longa distância. O objetivo é permitir que pesquisadores de qualquer lugar consultem documentos ligados entre si, sem precisar saber onde cada arquivo está guardado.

Sobre o projeto

Documentos são escritos em HTML e ligados por hiperlinks. Cada documento tem um endereço único, que depois ficou conhecido como URL.

Resumo dos conceitos

  • Hipertexto: texto com ligações para outros textos.
  • HTTP: protocolo simples para pedir e receber documentos.
  • HTML: linguagem de marcação para escrever as páginas.
  • URL: endereço que identifica cada recurso na rede.

Programas navegadores

Navegadores em modo texto funcionam em qualquer terminal.

Servidores de informação

Qualquer máquina na rede pode servir páginas para os demais.
